## 暂缓或调整

- **严格五气泡陪玩、20 秒两条预读、精确字数和停止词规则**：按用户最新意向不照搬，先用 MaiBot 自然聊天。陪玩对其他 bot 的原生命令是否足够可靠，待实际群聊评估。
- **各群独立模式**：当前宿主人设切换是全局的。多群独立模式需单独扩展。
- **长期记忆的语义检索**：角色资料已进入固定系统上下文，不靠重复向聊天窗口发提醒。跨轮长期个人记忆检索还需要选定嵌入模型并启用 A_Memorix；暂未假设 ChatGPT 接口提供 embeddings。
- **Office/PDF 内容解析**：当前原生附件工具主要读取文本；可保存和收发二进制文件，但不会声称已经理解内容。需要补解析器后再启用。
- **公式、Mermaid、长报告自动文件化**：表格已有工具入口；复杂公式、流程图、整段混排的自动拦截与保序发送尚未移植。不要把表格工具当成所有格式均已完成。
- **联网搜索**：新增可选普通 ChatGPT 任务服务的 `web_search` 工具，离线队列与插件测试通过，真实联网与窗口操作仍需端到端验收。
- **窗口任务服务**：已独立提取普通 ChatGPT 上传、提交、回复和媒体提取组件；默认关闭，不启动旧 QQ 监听，也不包含 OpenWebUI 后端。详见 hybrid-worker.md。
- **旧任务状态、旧数据库**：不导入旧程序“待核查”任务或重发队列。旧项目作为独立回退保留。
- **错误重试按钮和图片重发界面**：使用原生任务管理与日志先观察；扩展输出已缓存，但尚未提供专门的缓存重发按钮。

## 部署者需要配置

1. 自己的 QQ 账号、允许的群和模型/API 凭据。
2. 需要生图时配置支持图片模型的接口，或启用普通 ChatGPT 窗口任务服务。
3. 使用手机完成 NapCat 登录，并在允许的测试群逐项验收。

## 公开副本的验证范围

Python 回归测试覆盖配置、工具调用、来源聊天路由、附件校验和异常不重发；Node 测试覆盖窗口任务队列、HTTP 鉴权、幂等、重启恢复和回复提取。Windows 原生适配器可从本仓库源码编译。真实聊天/图片/文件结果取决于部署环境，不在公开文档记录私人账号、聊天内容、消息 ID、服务分组错误或聊天回执。
