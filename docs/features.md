# 功能与部署验收

| 能力 | 实现与限制 |
|---|---|
| QQ 收发 | MaiBot + 官方 QQ 连接器 + NapCat，按来源会话路由 |
| 聊天与识图 | 可配置 API、模型及推理强度，原生 Planner/Replyer |
| 连续消息与引用 | 原生上下文、防抖与消息组件，需要实际群聊验收 |
| 人设模式 | 三种通用示例，/模式 切换，当前为全局模式 |
| 文件 | 10 MiB 上限，复杂内容解析取决于工具能力 |
| 搜索 | 隔离 Codex ACP，独立搜索档位和两轮软预算，资料交回人设回复 |
| 生图与表情 | API 或 Codex，先缓存再投递；明确作图不受闲聊配图概率影响 |
| 表格 | render_table 排版为图片，失败保留原文 |
| 记忆与表情库 | 原生能力，语义检索需要配置嵌入模型 |
| 重试 | 有界重试，提交或发送结果不确定时不自动重放 |
| 启动 | 双击 run.cmd，配置检查与真实插件健康检查 |
| 恢复 | 非关键插件统计损坏时先备份再重建，不修改聊天数据库 |
| 迁移 | config/local、config/generated 和运行数据与源码分离 |

## 使用者验收

配置自己的 API Key、QQ 账号与允许的群，分别验证文字、识图、工具、搜索、生图、文件和原生提及。模型可见不等于全部接口可用。记忆、自动表情注册及嵌入模型需分别在原生面板配置。

严格五气泡陪玩、固定秒数预读、各群独立模式、复杂公式/流程图自动转图和缓存附件重发界面尚未作为完整迁移能力交付。不导入旧项目的任务队列或登录态。备用窗口服务默认关闭。
